How I work

A consistent approach to every build

schema first

Model the data before the screen

Entities, relationships, and migrations get designed before a single component is built — every project here has a real schema behind it, not mock JSON.

auth by default

JWT and role checks aren't an afterthought

Every multi-user app in this list ships with Spring Security, token-based auth, and — where it matters — a permission layer, not just a login screen.

built to be used

Admin panels, not just APIs

Most of these projects include a functional admin or dashboard view, on the principle that an API only I can operate isn't a finished product.
